
# Common Technical Errors

## Blank Screen

If the application shows a blank screen, clear the application cache, restart it, and install the latest supported version. If the error continues, record the error text and operating system for support.

## Application Crashes

If the application crashes whenever it is opened, restart the application and the device. Check whether the application is running the latest supported version. If the issue continues, record the exact error message, operating system, device details, and steps that caused the crash.

## Application Startup Failures

If the application fails to start, check the internet connection, verify that the device meets the application's system requirements, and restart the application. If the problem persists, record the error message and installation details for technical support.

## Persistent Error Messages

If an error message continues to appear, record its exact text and the action that triggered it. Do not repeatedly retry operations that may affect customer data. Share the error details and operating system with technical support for further investigation.
